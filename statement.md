# Project Statement

## 1. Problem Statement

In villages, people may not have all the information about development works carried out over the previous years in one place.

It can be difficult to remember which development works were completed, which leader was associated with a particular work, and what public feedback was given about those works.

Neta Parakh provides a simple system to store development work records, public ratings, and feedback in one place. This information can be viewed and compared during the election period.

---

## 2. Scope of the Project

The scope of Neta Parakh includes maintaining information about village development works and associated leaders.

The system allows users to:

- View leader information.
- View development works.
- View details of recorded works.
- Give ratings and feedback for works.
- Store feedback using file handling.
- View feedback through the Admin module.
- Compare leaders using recorded ratings and feedback.

The current project is a basic Python-based system using text-file storage. It is designed as a working prototype and can be expanded in the future.

---

## 3. Target Users

### Public / Villagers

Villagers can view development works, give ratings and feedback, and compare the available information about leaders.

### Leaders

Leaders can view their profile and the development works associated with them.

### Admin

The admin can view recorded development works and public feedback.

---

## 4. High-Level Features

- Leader information management
- Development work records
- Public feedback and rating system
- Feedback file storage
- Admin feedback viewing
- Leader comparison
- Total points calculation
- Average rating calculation
- Simple menu-based Python interface
